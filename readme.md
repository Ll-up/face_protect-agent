# FaceProtect：面向个性化护肤决策的 Agent 系统

> 基于 LangChain 构建的个性化护肤智能 Agent，通过本地 RAG、实时环境感知与 Human-in-the-Loop（HITL）机制，为用户提供更安全、更可信的护肤建议。

## ✨ 项目简介

传统的大语言模型虽然具备丰富的通识能力，但在护肤场景中仍存在明显局限：

* ❌ 无法感知用户所在地理位置及实时天气变化；
* ❌ 缺少用户长期肤质档案记忆，推荐缺乏个性化；
* ❌ 对涉及商品购买的 Tool Call 缺乏约束，存在“幻觉带货”的合规风险。

为解决上述问题，FaceProtect 构建了一套面向护肤决策场景的智能 Agent 系统，通过融合本地知识库、环境感知能力与人工确认机制，实现更精准、更可信的护肤建议生成。

---

## 🚀 核心功能

### 🌤️ 环境感知个性化推荐

结合用户：

* 地理位置
* 实时天气信息
* 用户肤质档案

动态分析当前皮肤状态及潜在风险，并生成针对性的护肤建议。

例如：

> 同样是干性皮肤用户，在“北京冬季低湿度”与“广州梅雨季高湿度”下，系统会生成不同的护肤方案与产品推荐。

---

### 📚 本地 RAG 护肤知识库

构建垂直领域知识增强系统：

* 爬取并整理 **200+ 份权威护肤指南**
* 使用 **BGE Embedding** 完成文本向量化
* 基于 **FAISS** 构建本地向量数据库
* 通过语义检索增强 LLM 回答准确性

避免模型完全依赖参数记忆导致的知识幻觉。

#### RAG 工作流程

```
用户问题
   ↓
向量检索（FAISS）
   ↓
召回相关护肤知识
   ↓
与用户档案、天气信息融合
   ↓
LLM 生成个性化建议
```

---

### 🛡️ Human-in-the-Loop（HITL）安全机制

针对涉及购买决策的敏感 Tool Call，引入人工确认流程。

当 Agent 检测到：

* 商品购买链接推荐；
* 电商平台跳转；
* 涉及消费行为的操作；

系统将：

```
Agent 提出推荐
      ↓
触发人工确认
      ↓
用户审核推荐内容
      ↓
确认后执行 Tool Call
```

该机制有效降低了：

* 大模型幻觉带货风险；
* 错误商品推荐导致的误导；
* 自动化消费行为的合规隐患。

## 🛠️ 技术栈

| 模块       | 技术选型                    |
| -------- | ----------------------- |
| Agent 框架 | LangChain               |
| 大语言模型    | 通义千问（Qwen）              |
| 向量模型     | BGE Embedding           |
| 向量数据库    | FAISS                   |
| 用户会话管理   | SessionManager          |
| 外部工具     | 天气 API、定位 API           |
| 安全机制     | Human-in-the-Loop（HITL） |

## 📈 项目效果

通过邀请 **20 名测试用户** 进行体验评估：

* ✅ Top-3 推荐被接受比例达到 **82%**
* ✅ 用户认为推荐结果较通用 AI 助手更加个性化
* ✅ HITL 机制提升了用户对购买推荐的信任度

---

## 💡 项目亮点

* 基于真实业务痛点设计 Agent，而非简单 ChatBot；
* 将 **RAG + 环境感知 + 用户画像** 融合到护肤决策流程；
* 引入 **Human-in-the-Loop** 提升推荐安全性与合规性；
* 从“能回答问题”升级为“辅助决策”的垂直领域智能体实践。
